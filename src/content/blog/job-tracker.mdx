##### What is Jobtracker?

Jobtracker is my most comprehensive personal project to date. Jobtracker is a full stack web application that allows users to track their job applications. I implemented it with React, Node, PostgreSQL, and TypeScript. You can interact with the project <ProjectLink text="here" link="https://job-tracker-phi.vercel.app/" />.

##### Technical Features

The website is relatively simple but in terms of technology, it has quite a few features.

### Frontend Features

1. Google Oauth authentication implemented with <ProjectLink text="NextAuth" link="https://job-tracker-phi.vercel.app/" />
2. Google Oauth token retrieval
3. Protected routes, users must login before accessing the application
4. Error handling with forms, server errors, and authorization issues

### Backend Features

1. Implemented backend as a RestAPI written in Node.js connected to a PostgreSQL db hosted on Supabase
2. Secured endpoints using Google Oauth token validation with Google's auth library
3. Implemented middleware in the RestAPI like loggers and error reporters
4. Error handling with forms, server errors, and authorization issues
5. Added unit testing with Node.js's testing module

##### Challenges

Prior to the current iteration of Job Tracker, I had actually made 2 versions of Job Tracker. This time, I knew how to set things up and had a good idea of what kind of product I wanted to make.

With this confidence, I managed to make a good prototype that could make and delete job applications. As I continued to work on this project, I had various responsibilities like school, work, and exercise that made it hard to stay committed. Furthermore, with the basics implemented, I had to work on more complex aspects of the websites like authentication.

I soon realized that the two biggest challenges of this project was staying commited and constantly learning new technology.

##### Lessons Learned

Through Job Tracker, I learned what it takes to stay commited working on a single project. I was very inconsistent with my progress and had to spend time to brainstorm strategies to stay committed. I used Trello and Notion to track my work and set weekly deadlines. I also made sure to review my progress on a weekly basis to make sure I was staying on time with my goals.

Patience was the most important lesson when it came to learning how to implement complex technology like authentication and token validation. I had to completely accept failure and be okay with making mistakes. I had to be okay with spending several days on the same problem. This was the heavy work of learning and Job Tracker taught me the importance of failing.
